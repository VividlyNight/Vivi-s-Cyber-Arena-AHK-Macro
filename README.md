A simple macro/automated program for earning Credits using AHK v2 for the Roblox game Cyber Arena! 
This is my first ever project, so please be patient with me!  
Please make sure to report any bugs or suggestions, I would love to hear them!

### In-Game Requirements (as of v1.0.0):
- Must have Brutal Mode unlocked
- [recommended] Have Viper Class or Negative Class unlocked

### Macro Requirements (as of v1.0.0):
- MUST have AHK v2 and MUST run on it  
- 1366x768 resolution  
- 100% Scale (change the size of text, apps, and other items)

### Roblox Requirements:
- Have the window FULLSCREEN (Press F11 on the keyboard, or turn Fullscreen on on the Roblox Settings)
- Graphics Quality 1
- Chat closed

### Things to NOT do (as of v1.0.0):
- Do not have anything that renames the application of Roblox itself, as the macro uses the name "RobloxPlayerBeta.exe" to detect the roblox window  
- Do not have any color altering filters on the virtual desktop as the macro relies on pixel color
- Do not have the Roblox window fullscreen, you have to maximize it (click the box icon of your window inbetween the Minimize [line] and the Close [X] 
- [recommended] Do not have any Roblox application open in the current virtual desktop, as turning on the macro will force-close all the Roblox tabs (incase if you are currently playing anything important)
