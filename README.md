# Vivi-s-Cyber-Arena-AHK-Macro
A simple macro using AHK v2 for the Roblox game Cyber Arena!

This is my first ever project, so please be patient with me

Please make sure to report any bugs or suggestions, I would love to hear them! My discord is VividlyNight

-------------------------------------------------------------------------------------------------------------------

In-Game Requirements (as of v1.0.0):
-Must have Brutal Mode unlocked

Macro Requirements (as of v1.0.0):
-MUST have AHK v2 and MUST run on it
-1366x768 resolution
-100% Scale (change the size of text, apps, and other items)

Roblox Requirements:
-Graphics quality 1

Things to NOT do (as of v1.0.0):
-[recommended] Do not have any Roblox application open in the current virtual desktop, as turning on the macro will force-close all the Roblox tabs
-Do not have anything that renames the application of Roblox itself, as the macro uses the name "RobloxPlayerBeta.exe" to detect the roblox window
-Have any color altering filters on the virtual desktop as the macro relies on pixel color
