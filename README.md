# Cyber Arena Macro Setup Guide

## Prerequisites & Installation

### 1. Install AutoHotKey
* Download and install **AutoHotKey v2** from the [Official AutoHotKey Website](https://www.autohotkey.com/).

### 2. Download the Macro
* Navigate to the Discord channel `#1532311347679854673`.
* Download the **latest version** of the macro (indicated by the `Latest` tag at the top of the channel).
* Launch the downloaded file to open the Macro Menu.

---

## Required System Settings

### 3. Display Configuration
* Set your monitor resolution to **1366x768**.
* Set your Windows display scale to **100%** (*"Change the size of text, apps, and other items"*).

---

## Game & Account Configuration

### 4. Private Server Setup
1. Create a Cyber Arena private server
2. Click **Edit** on your server settings
3. Enable **Allow Joins**
4. Click **Regenerate** on the Private Server Link, then copy it
5. Paste this link into the **Private Server** textbox inside the Macro Menu

### 5. Roblox Graphics & Window Settings
* **Fullscreen:** Press **F11** to make your Roblox window fully fullscreen (or enable it via the in-game Roblox settings)
* **Graphics Quality:** Manually lower your in-game Roblox Graphics Quality to **1**

### 6. In-Game Keybinds
Open Cyber Arena, click the **Settings** (yellow gear icon), select **Keybind**, and configure the following:
* **Roll / Dash:** `Left Control`
* **Shiftlock:** `Left Shift`
* or you can just set reset keybinds, it uses the default keybinds :P

### 7. Class Selection
* Equip a supported class and select your corresponding class option in the Macro Menu.
* *Supported classes (ranked worst to best):* **Patron** $\rightarrow$ **Negative** $\rightarrow$ **Viper**



## Things to NOT do (as of v1.0.0):
- Do not have anything that renames the application of Roblox itself, as the macro uses the name "RobloxPlayerBeta.exe" to detect the roblox window  
- Do not have any color altering filters on the virtual desktop as the macro relies on pixel color
- Do not have the Roblox window on non-fullscreen, you HAVE to have it on full screen!
- **[RECOMMENDED]** Do not have any Roblox application open in the current virtual desktop, as turning on the macro will force-close all the Roblox tabs (incase if you are currently playing anything important)
